Chatty MongoDB Services Query & Usage

Auth Service

Description: Manages authentication logic, including user creation, password reset, and user lookup by username, email, or token. Ensures secure handling of credentials and password reset flows.

Main Queries:
Aggregate Functionality:
  • Auth Service: No aggregate queries used.
AuthModel.create(data)
AuthModel.updateOne({ _id: authId }, { passwordResetToken, passwordResetExpires })
AuthModel.findOne({ username })
AuthModel.findOne({ email })
AuthModel.findOne({ passwordResetToken, passwordResetExpires: { $gt: Date.now() } })
Usage: Handles user creation, password reset token management, and user lookup by username/email/token.

Block User Service

Description: Handles blocking and unblocking of users. Updates the user's blocked and blockedBy lists to restrict or restore interactions between users.

Main Queries:
Aggregate Functionality:
  • Block User Service: No aggregate queries used.
UserModel.bulkWrite([
  { updateOne: { filter, update: { $push: { blocked } } } },
  { updateOne: { filter, update: { $push: { blockedBy } } } }
])
UserModel.bulkWrite([
  { updateOne: { filter, update: { $pull: { blocked } } } },
  { updateOne: { filter, update: { $pull: { blockedBy } } } }
])
Usage: Blocks or unblocks users by updating blocked/blockedBy arrays in user documents.

Chat Service

Description: Manages chat messages and conversations. Adds new messages, creates conversations if needed, and retrieves conversation lists for users.

Main Queries:
Aggregate Functionality:
  • Chat Service: Uses MessageModel.aggregate to group messages by conversation, filter by sender/receiver, and project the latest message in each conversation. This enables efficient retrieval of conversation lists and message summaries.
ConversationModel.find({ _id: conversationId })
ConversationModel.create({ ... })
MessageModel.create({ ... })
MessageModel.aggregate([
  { $match: { $or: [{ senderId }, { receiverId }] } },
  { $group: { _id: '$conversationId', result: { $last: '$$ROOT' } } },
  { $project: { ... } }
])
Usage: Adds messages, creates conversations, and fetches user conversation lists.

Comment Service

Description: Handles creation and retrieval of comments for posts. Also updates the comment count on posts and triggers notifications for new comments.

Main Queries:
Aggregate Functionality:
  • Comment Service: Uses CommentsModel.aggregate to filter and sort comments for a post, enabling efficient retrieval and ordering of comments.
CommentsModel.create(comment)
PostModel.findOneAndUpdate({ _id: postId }, { $inc: { commentsCount: 1 } })
CommentsModel.aggregate([{ $match: query }, { $sort: sort }])
Usage: Adds comments, updates post comment count, and fetches comments for a post.

Follower Service

Description: Manages user following relationships. Adds new followers, updates follower/following counts, and sends notifications for new follows.

Main Queries:
Aggregate Functionality:
  • Follower Service: No aggregate queries used.
FollowerModel.create({ ... })
UserModel.bulkWrite([
  { updateOne: { filter, update: { $inc: { followingCount } } } },
  { updateOne: { filter, update: { $inc: { followersCount } } } }
])
Usage: Adds followers, updates following/follower counts, and triggers notifications.

Image Service

Description: Handles user images, including profile and background images. Adds, updates, deletes, and retrieves image records for users.

Main Queries:
Aggregate Functionality:
  • Image Service: Uses ImageModel.aggregate to filter images by user, allowing efficient retrieval of all images for a specific user.
UserModel.updateOne({ _id: userId }, { $set: { profilePicture: url } })
UserModel.updateOne({ _id: userId }, { $set: { bgImageId, bgImageVersion } })
ImageModel.create({ ... })
ImageModel.deleteOne({ _id: imageId })
ImageModel.findOne({ bgImageId })
ImageModel.aggregate([{ $match: { userId } }])
Usage: Manages user profile/background images and image records.

Notification Service

Description: Manages notifications for users. Fetches notifications, marks them as read, and deletes them as needed. Integrates with user and auth data for richer notification details.

Main Queries:
Aggregate Functionality:
  • Notification Service: Uses NotificationModel.aggregate to join notification data with user and auth collections, unwind arrays, and project enriched notification details for the user.
NotificationModel.aggregate([
  { $match: { userTo } },
  { $lookup: { from: 'User', localField: 'userFrom', foreignField: '_id', as: 'userFrom' } },
  { $unwind: '$userFrom' },
  { $lookup: { from: 'Auth', localField: 'userFrom.authId', foreignField: '_id', as: 'authId' } },
  { $unwind: '$authId' },
  { $project: { ... } }
])
NotificationModel.updateOne({ _id: notificationId }, { $set: { read: true } })
NotificationModel.deleteOne({ _id: notificationId })
Usage: Fetches, updates, and deletes notifications for users.

Post Service

Description: Handles post creation, retrieval, updating, and deletion. Also manages post counts for users and supports filtering by images, videos, and other criteria.

Main Queries:
Aggregate Functionality:
  • Post Service: Uses PostModel.aggregate to filter, sort, skip, and limit posts for pagination and advanced querying (e.g., by image, video, or other criteria).
PostModel.create(createdPost)
UserModel.updateOne({ _id: userId }, { $inc: { postsCount: 1 } })
PostModel.aggregate([{ $match: postQuery }, { $sort: sort }, { $skip: skip }, { $limit: limit }])
PostModel.find({}).countDocuments()
PostModel.deleteOne({ _id: postId })
UserModel.updateOne({ _id: userId }, { $inc: { postsCount: -1 } })
PostModel.updateOne({ _id: postId }, { $set: updatedPost })
Usage: Adds, fetches, updates, and deletes posts, and manages post counts.

Reaction Service

Description: Manages reactions to posts. Adds or updates reaction records and updates reaction counts on posts. Also triggers notifications for new reactions.

Main Queries:
Aggregate Functionality:
  • Reaction Service: No aggregate queries used.
ReactionModel.replaceOne({ postId, type, username }, reactionObject, { upsert: true })
PostModel.findOneAndUpdate({ _id: postId }, { $inc: { [`reactions.${previousReaction}`]: -1, [`reactions.${type}`]: 1 } })
Usage: Adds or updates reactions, and updates reaction counts on posts.

User Service

Description: Manages user data, including creation, password updates, profile info, social links, notification settings, and user lookups. Supports aggregation with auth data for richer user profiles.

Main Queries:
Aggregate Functionality:
  • User Service: Uses UserModel.aggregate to join user data with auth data, unwind arrays, and project enriched user profiles for lookups by userId or authId.
UserModel.create(data)
AuthModel.updateOne({ username }, { $set: { password: hashedPassword } })
UserModel.updateOne({ _id: userId }, { $set: { work, school, quote, location } })
UserModel.updateOne({ _id: userId }, { $set: { social: links } })
UserModel.updateOne({ _id: userId }, { $set: { notifications: settings } })
UserModel.aggregate([
  { $match: { _id: userId } },
  { $lookup: { from: 'Auth', localField: 'authId', foreignField: '_id', as: 'authId' } },
  { $unwind: '$authId' },
  { $project: ... }
])
UserModel.aggregate([
  { $match: { authId } },
  { $lookup: { from: 'Auth', localField: 'authId', foreignField: '_id', as: 'authId' } },
  { $unwind: '$authId' },
  { $project: ... }
])
Usage: Manages user creation, password, info, social links, notification settings, and user lookups.
