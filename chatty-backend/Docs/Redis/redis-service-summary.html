Chatty Redis Cache Services Summary

Redis Commands Overview

Description: Redis is an in-memory data store used for caching and fast data access. Below are common Redis commands used in this project and their typical usage:

CommandUsageDescription
LPUSH key valueAdds value to the left of a listUsed to add items (e.g., comments, followers) to a list
RPUSH key valueAdds value to the right of a listUsed to append items (e.g., chat messages) to a list
LRANGE key start endGets a range of items from a listUsed to retrieve all or part of a list (e.g., all comments)
LLEN keyGets the length of a listUsed to count items in a list (e.g., number of comments)
LREM key count valueRemoves items from a listUsed to remove specific items (e.g., followers, reactions)
HSET key field valueSets a field in a hashUsed to store structured data (e.g., post metadata, user profile)
HMGET key field [field ...]Gets one or more fields from a hashUsed to retrieve specific fields (e.g., comment count)
HINCRBY key field incrementIncrements a field in a hashUsed to update counters (e.g., follower count)
DEL keyDeletes a keyUsed to remove data from cache
connect()Connects to Redis serverEstablishes connection for cache operations
ping()Pings Redis serverChecks connection status

These commands are used throughout the cache services to efficiently store, retrieve, and manage data for fast access and scalability.

Base Cache

Description: Abstract base class for all cache services. Handles Redis client connection and error logging.

Main Commands:
createClient({ url })        // Create a Redis client connection
client.on('error', ...)      // Log Redis connection errors

Comment Cache

Description: Manages caching of post comments. Supports saving, retrieving, and counting comments for posts using Redis lists and hashes.

Main Commands:
LPUSH `comments:${postId}` value           // Add a comment to the post's comment list
HMGET `posts:${postId}` 'commentsCount'    // Get the number of comments for a post
HSET `posts:${postId}` 'commentsCount' count // Update the comment count for a post
LRANGE `comments:${postId}` 0 -1           // Retrieve all comments for a post
LLEN `comments:${postId}`                  // Get the length of the comment list

Follower Cache

Description: Handles caching of followers and following relationships. Supports adding/removing followers and updating follower counts using Redis lists and hashes.

Main Commands:
LPUSH key value                      // Add a follower/following to the list
LREM key 1 value                     // Remove a follower/following from the list
HINCRBY `users:${userId}` prop value // Increment follower/following count
LRANGE key 0 -1                      // Retrieve all followers/following

Message Cache

Description: Caches chat messages, chat lists, and chat users. Supports adding messages, chat lists, and users, and retrieving them using Redis lists.

Main Commands:
LRANGE `chatList:${senderId}` 0 -1           // Get chat list for a user
RPUSH `chatList:${senderId}` value           // Add a chat to the user's chat list
RPUSH `messages:${conversationId}` value     // Add a message to a conversation
RPUSH 'chatUsers' value                      // Add chat users to the global list

Post Cache

Description: Manages caching of posts and their metadata. Supports saving, retrieving, and updating posts and reactions using Redis hashes and lists.

Main Commands:
HSET `posts:${postId}` field value   // Set a field (e.g., reactions, commentsCount) for a post
LPUSH `posts` value                  // Add a post to the posts list
LRANGE `posts` 0 -1                  // Retrieve all posts

Reaction Cache

Description: Handles caching of post reactions. Supports saving, removing, and retrieving reactions for posts using Redis lists and hashes.

Main Commands:
LPUSH `reactions:${key}` value           // Add a reaction to the post's reaction list
HSET `posts:${key}` 'reactions' value    // Update the reactions field for a post
LRANGE `reactions:${key}` 0 -1           // Retrieve all reactions for a post
LREM `reactions:${key}` 1 value          // Remove a reaction from the post's reaction list

Redis Connection

Description: Manages the connection to the Redis server. Handles connecting and pinging the Redis instance.

Main Commands:
client.connect()    // Connect to the Redis server
client.ping()       // Ping the Redis server to check connection

User Cache

Description: Caches user data, including profile, social links, notification settings, and counts. Supports saving and retrieving user data using Redis hashes and lists.

Main Commands:
HSET `users:${userId}` field value   // Set a field (e.g., profile, social, notifications) for a user
LPUSH `users` value                  // Add a user to the users list
LRANGE `users` 0 -1                  // Retrieve all users
