Lifecycle Hooks

  1. before_install.sh: Prepares the EC2 instance (updates packages, installs dependencies). 
    # scripts/before_install.sh
#!/bin/bash
sudo yum update -y
# Install Node.js, npm, etc.
  2. after_install.sh: Installs npm packages, sets permissions, etc. 
    # scripts/after_install.sh
#!/bin/bash
cd /home/ec2-user/chatty-backend
npm install
  3. application_start.sh: Starts the Node.js server (e.g., with PM2 or npm). 
    # scripts/application_start.sh
#!/bin/bash
cd /home/ec2-user/chatty-backend
npm run start:prod
Reference: See appspec.yml for how these scripts are triggered by AWS CodeDeploy hooks.
Best Practice: Log output from each script to a file for debugging (e.g., exec &> /tmp/deploy.log).
