Deployment Lifecycle

  1. appspec.yml: Central config for AWS CodeDeploy. Defines which files to copy and which scripts to run at each lifecycle stage.
  2. Hooks:
    • BeforeInstall: Prepares the instance (updates, installs).
    • AfterInstall: Installs dependencies, sets up app.
    • ApplicationStart: Starts the Node.js server.
  3. File Copy: files section copies source to EC2 destination. file_exists_behavior: OVERWRITE ensures files are replaced.
  4. Logs & Rollback: CodeDeploy logs are available on EC2 at /var/log/aws/codedeploy-agent/. Failed deployments trigger automatic rollback.
# Example: appspec.yml
version: 0.0
os: linux
files:
  - source: /
    destination: /home/ec2-user/chatty-backend
hooks:
  BeforeInstall:
    - location: scripts/before_install.sh
      timeout: 300
      runas: root
  AfterInstall:
    - location: scripts/after_install.sh
      timeout: 300
      runas: root
  ApplicationStart:
    - location: scripts/application_start.sh
      timeout: 300
      runas: root
file_exists_behavior: OVERWRITE
Troubleshooting: If deployment fails, check CodeDeploy logs and script output. Ensure scripts are executable (chmod +x), and paths are correct.
