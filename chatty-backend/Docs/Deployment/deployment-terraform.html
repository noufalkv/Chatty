Terraform Workflow

Terraform lets you define your entire cloud infrastructure as code. This means you can create, update, and destroy AWS resources automatically and consistently. The steps below explain how to use Terraform for Chatty backend deployments.

  1. Install Terraform: Download from terraform.io and verify with terraform -v. This tool will manage all AWS resources for you.
  2. Edit Variables: Update deployment/1-variables.tf with your project-specific values (region, prefix, S3 bucket, etc.). This file controls your deployment environment and naming conventions.
  3. Initialize: Run terraform init in the deployment folder. This sets up providers and remote state, preparing Terraform to manage your infrastructure.
  4. Plan & Apply: Use terraform plan to preview changes, then terraform apply -auto-approve to create/update resources. This step provisions everything in AWS automatically.
  5. Destroy: When you need to remove all resources, run terraform destroy. This is useful for cleaning up test environments or starting fresh.
