Workflow & Configuration

  1. Edit .circleci/config.yml to define jobs for build, test, deploy. 
    jobs:
  build:
    docker:
      - image: circleci/node:16
    steps:
      - checkout
      - run: npm install
      - run: npm run test
  2. Add AWS credentials, CodeDeploy settings, CodeCov token, Slack webhook, etc. in CircleCI project settings.
  3. Define workflow to run jobs in sequence (build → test → deploy). Use filters for branches (e.g., only deploy on develop).
  4. Integrate Slack for build/deploy notifications.
  5. Replace <variable-prefix> in config.yml with your Terraform prefix value.
Reference: See README.md for screenshots and environment variable setup.
Troubleshooting: If builds fail, check CircleCI job logs, ensure environment variables are set, and verify AWS permissions.
