Welcome

This deployment documentation is designed to guide you through every step required to launch, manage, and maintain the Chatty backend on AWS. Each section provides practical instructions, explanations, and best practices for a smooth and reliable deployment experience.

How to use: Start with AWS Setup to prepare your cloud environment, then follow each section in order. Each page contains detailed breakdowns, code samples, troubleshooting tips, and real-world advice.

  • AWS Setup: Learn how to create your AWS account, configure IAM users, set up Route53 for DNS, create S3 buckets for environment files and Terraform state, and prepare your environment variables.
    Why? These steps ensure your cloud foundation is secure, organized, and ready for automation.
  • Terraform: Discover how to use infrastructure as code to provision all AWS resources. Includes workflow, file map, and troubleshooting.
    Why? Terraform automates resource creation, making deployments repeatable and scalable.
  • Scripts: Understand the deployment lifecycle scripts (before_install, after_install, application_start), their roles, and how they interact with CodeDeploy.
    Why? Scripts automate setup, installation, and app startup for every deployment.
  • CI/CD: Set up CircleCI for automated build, test, and deployment. Learn about configuration, environment variables, and workflow.
    Why? CI/CD ensures code quality and fast, reliable releases.
  • CodeDeploy: Explore AppSpec configuration, deployment hooks, logs, and troubleshooting.
    Why? CodeDeploy manages the deployment process and rollback for reliability.
  • Infrastructure Files: Reference all key files, their purposes, and find answers to common deployment questions.
    Why? Knowing your file map helps with debugging and team collaboration.
