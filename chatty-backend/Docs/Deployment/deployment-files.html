File Map

  • deployment/:
    • 1-variables.tf: Project variables
    • 3-main.tf: Remote state config
    • 4-vpc.tf ... 26-code_deploy.tf: AWS resources
    • userdata/: EC2 initialization scripts
  • scripts/:
    • before_install.sh: Pre-install tasks
    • after_install.sh: Post-install tasks
    • application_start.sh: Start app
  • appspec.yml: CodeDeploy configuration and hooks
  • .circleci/config.yml: CI/CD pipeline jobs and workflows
  • README.md: Full documentation, setup, and troubleshooting
Tip: For troubleshooting, check AWS CodeDeploy logs and CircleCI build logs.
FAQ:
  • Q: Why is my EC2 instance not starting the app?
    A: Check application_start.sh logs and ensure Node.js is installed.
  • Q: Terraform apply fails with permission error.
    A: Verify IAM user policies and S3 bucket access.
  • Q: CodeDeploy rollback triggered.
    A: Review script output and make sure all paths and permissions are correct.
